1. نظرة عامة ورؤية المشروع
-------------------------------------------------------------------------------
تطبيق "وسلني" (Wasalni) هو منصة ذكية ومتقدمة لمشاركة الرحلات السفرية بين المدن
(Carpooling & Intercity Rides). التطبيق مصمم ليعمل كـ Client واجهة مستخدم ناعمة 
وباك إند جاهز للربط المستقبلي المباشر مع بوت تيليغرام (Telegram Bot Interface) 
دون الحاجة لنشر التطبيق على متجر Google Play.

2. خيارات وصلاحيات المستخدم العادي (User Capabilities)
-------------------------------------------------------------------------------
عند تسجيل المستخدم وحصوله على الحساب، يستطيع القيام بالعمليات التالية:

أ) التسجيل وتسجيل الدخول:
   - يحصل المستخدم الجديد تلقائياً وبشكل مجاني على [50 نقطة] كهدية ترحيبية عند أول تسجيل.
   - التحقق عبر رقم الهاتف ورمز التأكيد OTP لحماية الحسابات.
   - يدعم نظام كود الإحالة (Referral System) حيث يمنح الداعي 100 نقطة مجانية.
   - بعد تسجيل الدخول، يختفي خيار "تسجيل الدخول" من القائمة ويتغير تلقائياً إلى "تسجيل الخروج" مع عرض كرت الملف الشخصي والرصيد الحالي.

ب) نشر رحلة جديدة (Driver Role):
   - عند نشر أي رحلة جديدة، يتم خصم 50 نقطة فقط من محفظة المستخدم.
   - يحدد السائق البيانات التالية بدقة:
     1. مدينة الانطلاق (Start City) ومدينة الوصول (Destination).
     2. تاريخ الرحلة وتوقيتها (Date & Time).
     3. نوع وموديل السيارة (Car Model) - مثل: تويوتا كامري 2022 / كيا سيراتو.
     4. لون السيارة (Car Color) - مثل: فضي / أبيض / أسود.
     5. رقم لوحة السيارة (Car Plate) - مثل: دمشق 892103.
     6. عدد المقاعد المتاحة (Available Seats).
     7. سعر المقعد الواحد (Price per seat).
     8. خيارات إضافية: رحلات مخصصة للنساء فقط (Women-Only) / إمكانية نقل الأمتعة (Luggage Allowed).

ج) البحث وحجز الرحلات (Passenger Role):
   - البحث بحسب مدينة المغادرة والوصول والتاريخ وعدد الركاب.
   - تصفية نتائج البحث (فلترة رحلات النساء فقط، السائقين الموثقين، الأعلى تقييماً).
   - استعراض تفاصيل الرحلة ومعاينة بيانات السيارة وسجل السائق قبل الحجز.
   - تأكيد الحجز وخصم المقعد المتاح تلقائياً.

د) قائمة الرحلات المطلوبة (Requested Trips / طلب رحلة):
   - إمكانية تثبيت طلب رحلة في القائمة العامة إذا لم يجد المستخدم رحلة تناسبه.
   - تحديد عدد الركاب (رجال، نساء، أطفال)، التاريخ، والوقت.
   - إمكانية قبول الطلب من قبل أي سائق موثق وتحويله فوراً إلى رحلة مجدولة.

هـ) المحفظة والشحن (Wallet & Cham Cash Top-Up):
   - استعراض رصيد النقاط وسجل المعاملات (خصم الشحن، الهدايا، الخصومات).
   - طلب شحن رصيد عبر تحويل شام كاش (Cham Cash) الموحد.
   - رفع صورة إشعار التحويل وانتظار موافقة الأدمن لتفعيل النقاط.

و) المحادثات والمراسلة (In-App Messaging):
   - شات مباشر بين الراكب والسائق للتنسيق حول مكان الالتقاء.
   - إمكانية مشاركة الموقع الجغرافي، إرسال الصور، وتنبيهات التذكير بالدفع.

4. جاهزية الباك إند والربط مع بوت تيليغرام (Telegram Bot Readiness)
-------------------------------------------------------------------------------
التطبيق مبني بنمطه الحالي ليكون الباك إند والمحرك المباشر لبوت تيليغرام القادم:

أ) بنية البيانات والرسائل (Command Dispatcher):
   يتضمن الـ ViewModel والـ DAOs مسارات استقبال ومعالجة الأوامر من بوت تيليغرام مباشرة:
   - /start : بدء البوت والتعريف بالخدمة.
   - /rides : جلب قائمة الرحلات المتاحة واستعراض نوع السيارة، اللوحة، اللون والسعر.
   - /points : استعلام المستخدم عن رصيد نقاطه الحالية (50 نقطة للجدد).
   - /publish : نشر رحلة جديدة بربط البيانات عبر التيليغرام.

ب) معالجة الأحداث والـ Webhooks:
   - القاعدة البيانات المحلية Room متوافقة مع JSON Export/Import ومحولة لتسلسل payloads تيليغرام.
   - السائق والمستخدم يستطيعون تلقي التنبيهات عبر Telegram Chat ID المربوط برقم الهاتف.

5. عناصر واجهة المستخدم والـ Navbar
-------------------------------------------------------------------------------
أ) الشريط العلوي (Header Bar):
   - كرت رصيد النقاط (الضغط عليه يفتح المحفظة).
   - أيقونة الإشعارات مع عداد الإشعارات غير المقروءة.
   - أيقونة الإعدادات (تغيير اللغة، المظهر الداكن، تعديل البروفايل).
   - زر تسجيل الدخول / البروفايل الشخصي (يتحول لـ "تسجيل الخروج" عند تسجيل الدخول).

ب) شريط التنقل السفلي (Bottom Navigation Bar):
   1. بحث (Search): البحث عن رحلات واكتشاف العروض.
   2. رحلاتي (My Rides): متابعة الرحلات المحجوزة والرحلات المنشورة للسائق.
   3. نشر رحلة (Publish): إضافة رحلة مع تفاصيل السيارة وتحديد السعر.
   4. الرسائل (Messages): الشات والتواصل المباشر.
   5. المحفظة (Wallet): الشحن ورموز الإحالة والتحويل عبر شام كاش.
