================================================================================
                    تطبيق وصلني (Wasalni App) - الوثيقة الشاملة
================================================================================
تاريخ التوثيق: 2026-08-10
اسم التطبيق: وصلني (Wasalni)
نوع التطبيق: منصة تشاركية ذكية للرحلات، نقل الركاب، الطلبات الخاصة والنزول، وإدارة المحفظة والنقاط.

--------------------------------------------------------------------------------
1. المزايا والخصائص العامة للتطبيق (General Features & Tech Stack)
--------------------------------------------------------------------------------
• تصميم عصري وأنيق قائم على نظام Glassmorphism (البطاقات الزجاجية والمؤثرات البصرية).
• دعم شامل للغتين العربية والإنجليزية (RTL / LTR) مع إمكانية التبديل الفوري.
• دعم الوضع المظلم (Dark Mode) والوضع الفاتح (Light Mode).
• التوافق التام مع مختلف أحجام الشاشات وتجاوز مشاكل الأبعاد في كافة الهواتف (مثل Tecno, Samsung, Xiaomi وغيرها).
• استخدام أحدث تقنيات أندرويد (Kotlin, Jetpack Compose, Material Design 3, Coroutines, StateFlow).
• قاعدة بيانات محلية سريعة وسلسة باستخدام Room Database لدعم العمل دون انقطاع.
• جاهزية ربط كاملة مع خدمات سحابة Google Firebase (Authentication, Firestore, Messaging, Analytics).
• بناء وتكامل خطوط النشر الآلي عبر GitHub Actions وإنشاء ملفات AAB و APK الموقعة لمتجر Google Play.

--------------------------------------------------------------------------------
2. ووظائف وخصائص المستخدمين (User Features & Capabilities)
--------------------------------------------------------------------------------

[أ] البحث عن رحلات (Ride Search & Filtering):
   - تحديد مدينة الانطلاق ومدينة الوصول.
   - اختيار تاريخ السفر وعدد المقاعد المطلوبة.
   - تصفية نتائج البحث وحفظ خيارات البحث الأخيرة.
   - عرض الرحلات المتاحة بتفاصيل دقيقة (اسم السائق، تقييمه، نوع السيارة، السعر، عدد المقاعد الشاغرة، وتوقيت التحرك).

[ب] نشر رحلة جديدة (Publish Ride - للسائقين):
   - اختيار خط السير (من / إلى).
   - تحديد تاريخ ووقت الانطلاق.
   - تحديد عدد المقاعد المتاحة وسعر المقعد الواحد.
   - إضافة ملاحظات خاصة بالرحلة (مثل: السماح بالأمتعة، منع التدخين، التوقف في الطريق).
   - تحديد مكان التجمع والنزول.

[ج] الطلبات الخاصة ورحلات النزول (Requested Trips & Courier):
   - إنشاء طلب رحلة خاصة في حال عدم وجود رحلة تناسب الراكب.
   - خيار طلب نقل طرود أو بضائع خاصة.
   - استعراض طلبات الركاب من قبل السائقين وقبولها أو تقديم عروض عليها.

[د] تفاصيل الرحلة وحجز المقاعد (Ride Details & Booking):
   - عرض شاشة تفصيلية لكل رحلة تشمل خريطة/مسار الرحلة، تفاصيل السائق ورقم التواصل.
   - زر الحجز المباشر للمقاعد مع خصم النقاط أو التأكيد الفوري.
   - زر التواصل المباشر مع السائق عبر الاتصال الهاتفي أو محادثة WhatsApp.
   - خيار إلغاء الحجز أو مشاركة تفاصيل الرحلة مع الأصدقاء.

[هـ] المحفظة الرقمية ونظام النقاط (Wallet & Points System):
   - عرض رصيد النقاط الحالي بشكل بارز.
   - إمكانية طلب شحن المحفظة (عن طريق كروت الشحن، التحويل المباشر، أو وسائل الدفع المتاحة).
   - سجل التأسيس والعمليات (Transaction History) لجميع عمليات الشحن والخصم.
   - نظام دعوة صديق (Referral Program): كود إحالة خاص لكل مستخدم، مع إمكانية مشاركته بنقرة واحدة عبر WhatsApp أو النسخ المباشر للحصول على 100 نقطة مجانية فور تسجيل الصديق.

[و] نظام الدردشة والرسائل (Messaging System):
   - محادثات فورية ومباشرة بين الراكب والسائق للتنسيق حول مكان اللقاء.
   - قائمة بجميع الرسائل والمحادثات النشطة مع إشعارات الرسائل الجديدة.

[ز] التقييمات والمراجعات (Rating & Reviews):
   - تقييم السائقين والركاب بعد ختام كل رحلة بنظام 5 نجوم.
   - إمكانية إضافة تعليق وملاحظات على جودة الرحلة.
   - عرض التقييم التجميعي في الملف الشخصي وفي نتائج البحث.

[ح] رحلاتي (My Rides Dashboard):
   - عرض الرحلات القادمة والنشطة.
   - عرض سجل الرحلات المنتهية والملغاة.
   - زر إدارة الرحلة للسائق (تعديل، إلغاء، أو إنهاء الرحلة).

--------------------------------------------------------------------------------
3. ووظائف وخصائص الأدمن - لوحة التحكم (Admin Dashboard Features)
--------------------------------------------------------------------------------
تتيح لوحة التحكم للإدارة السيطرة الكاملة على كافة عمليات التطبيق:

[أ] إدارة طلبات شحن المحفظة (Wallet Top-Up Approvals):
   - استعراض جميع طلبات الشحن المقدمة من المستخدمين.
   - فحص تفاصيل الطلب (اسم المستخدم، المبلغ، رقم الكرت أو إيصال التحويل).
   - زر القبول المباشر (Approve) لإضافة النقاط تلقائياً لمحفظة المستخدم.
   - زر الرفض (Reject) مع توضيح السبب.

[ب] إدارة الإعلانات واللافتات (Banner & Ad Management):
   - إضافة إعلانات جديدة تظهر في أعلى الشاشات الرئيسية.
   - رفع صور الإعلانات، تحديد عناوينها، والروابط الخاصة بها.
   - تفعيل أو تعطيل الإعلانات الحالية أو حذفها.

[ج] إدارة أكواد الخصم والعروض (Promo Codes):
   - إنشاء كود خصم جديد (رمز الكود، نسبة/مقدار الخصم بالنقاط، تاريخ الانتهاء).
   - تحديد الحد الأقصى لاستخدام الكود.
   - متابعة عمليات استخدام الكود من قبل المستخدمين.

[د] إدارة الرحلات والطلبات العامة:
   - مراجعة جميع الرحلات المنشورة والطلبات الخاصة في النظام.
   - إمكانية حظر أو إيقاف رحلة مخالفة.
   - متابعة إحصائيات التطبيق الشاملة: عدد الرحلات النشطة، إجمالي المستخدمين، مجموع النقاط المشحونة، وعدد الطلبات المكتملة.

--------------------------------------------------------------------------------
4. عناصر الواجهة والتصميم (UI Components & Dialogs)
--------------------------------------------------------------------------------

[أ] شريط التنقل السفلي (BottomNavBar):
   - يتضمن 5 أقسام رئيسية مع أيقونات تفاعلية وشارات التنبيه:
     1. البحث (Search)
     2. الطلبات (Requested Trips)
     3. نشر رحلة / إضافة (+) (Publish Ride Button - بارز وفي المنتصف)
     4. رحلاتي (My Rides)
     5. محفظتي (Wallet)

[ب] الشريط العلوي (HeaderBar):
   - زر الملف الشخصي وتسجيل الدخول / الخروج.
   - زر مركز الإشعارات والتنبيهات (Notification Center) مع شارة عدد التنبيهات غير المقروءة.
   - زر الإعدادات (Settings).
   - عرض مختصر لرصيد النقاط مع زر الانتقال السريع للمحفظة.

[ج] البطاقات الزجاجية (GlassCard):
   - مكون واجهة مخصص يضفي مظهر أبل وزجاجي عصري بخلفيات ناعمة وحدود مضيئة حواف منحنية.

[د] النوافذ المنبثقة (Dialogs & Modals):
   - AuthDialog: نافذة تسجيل الدخول وإنشاء حساب جديد بسلاسة.
   - SettingsDialog: نافذة الإعدادات للتحكم باللغة (عربي/إنجليزي)، الوضع المظلم، وشروط الاستخدام.
   - NotificationCenterDialog: قائمة عرض جميع التنبيهات الواردة للمستخدم.
   - RatingDialog: نافذة تقييم الرحلة وكتابة الملاحظات.
   - TopUpModal: نافذة طلب شحن النقاط بجهة الأدمن.

--------------------------------------------------------------------------------
5. شاشات التطبيق الرئيسية (App Screens)
--------------------------------------------------------------------------------
1. SearchScreen: شاشة واجهة البحث الرئيسية ومحرك تصفية الرحلات.
2. SearchResultsScreen: شاشة عرض نتائج البحث وقائمة الرحلات المطابقة.
3. PublishRideScreen: شاشة إضافة ونشر رحلة جديدة للسائق.
4. RequestedTripsScreen: شاشة طلبات الرحلات الخاصة ونقل البضائع والنزول.
5. MyRidesScreen: شاشة إدارة متابعة رحلات المستخدم الحالية والسابقة.
6. MessagesScreen: شاشة المحادثات والدردشة المباشرة.
7. WalletScreen: شاشة المحفظة الرقمية، السجل، ودعوة الأصدقاء عبر واتساب.
8. RideDetailScreen: شاشة تفاصيل الرحلة الحالية وإجراء الحجز والتواصل.
9. AdminDashboardScreen: شاشة لوحة تحكم الأدمن للتحكم الكامل بالتطبيق.

--------------------------------------------------------------------------------
6. الملفات المجهزة للنشر على متجر Google Play
--------------------------------------------------------------------------------
• app/build.gradle.kts: إعدادات البناء والتوقيع للـ Release بالـ Target SDK 36.
• .github/workflows/build-apk.yml: سير العمل الآلي لبناء ملفات AAB و APK الموقعة.
• privacy-policy.html: سياسة الخصوصية باللغة العربية جاهزة للنشر.
• keystore.properties.example: نموذج بيانات ملف التوقيع الرقمي.
• app/google-services.json: ملف إعدادات سحابة Firebase.
